# NextJob User Guide

Welcome to the NextJob User Guide. This documentation covers all user flows to help you navigate onboarding, job applications, application tracking, and privacy controls.

## Table of Contents

- [Onboarding Guide](onboarding.md) — Account creation, profile import, claim verification, preferences, and automation policy configuration.
- [Applying Guide](applying.md) — Job discovery, capability model job cards, AI tailoring with evidence provenance, risk classifications, field approvals, and browser extension submissions.
- [Tracking Guide](tracking.md) — Application state lifecycle, views and filters, cryptographic submission receipts, and manual outcome updates.
- [Privacy Controls Guide](privacy-controls.md) — Inspection, correction, data export with SHA-256 checksums, cascading deletion, model training opt-outs, and integration disconnection.

## Core Principles

- **Proof over Promises:** Every generated factual statement in tailored materials traces directly to a verified career claim.
- **Privacy & Safety:** Sensitive fields (demographics, disability, health) are strictly user-only and never auto-filled or shared without explicit real-time consent.
- **Transparency:** All automated actions and submissions provide verifiable cryptographic submission receipts.
